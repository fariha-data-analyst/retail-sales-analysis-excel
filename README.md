Retail Sales & Profitability Analysis Dashboard (Excel)

Project Overview

This project presents an interactive Retail Sales & Profitability Analysis Dashboard built using Microsoft Excel. The dashboard provides key insights into revenue, profitability, product category performance, and regional sales distribution.

 Key Features & Tools Used
 
*Data Cleaning & Structuring: Organized raw retail dataset and formatted it into a structured Excel Table.
*Calculated Metrics: Applied Excel formulas to calculate core business KPIs:
  - Total Revenue
  - Total Cost
  - Total Profit
  - Profit Margin %
- Pivot Tables & Pivot Charts: Summarized sales and profit metrics grouped by product categories.
- Interactive Slicers: Embedded a Region Slicer allowing dynamic filtering across East, North, South, and West regions.

 Business Insights
- Identifies top-performing product categories based on revenue and profit margins.
- Helps analyze profit variations across different regions using interactive filtering.

Repository Structure
- Retail_Sales_and_Profitability_Analysis.xlsx: Complete Excel workbook containing raw data, calculations, Pivot Tables, Pivot Charts, and Slicers.
